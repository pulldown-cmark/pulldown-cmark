# Security Policy

## Supported Versions

Only the latest 0.x branch of pulldown-cmark receives security updates,
unless a previous version is explicitly indicated as patched.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| others  | :x:                |

## Reporting a Vulnerability

To report a vulnerability please use the repository private reporting in the
'Security and quality' tab.
